扩展域分类

  • 问题域：问题理解 + 特征提取 → 适合快速识别问题类型
  • 设计域：算法策略 + 数据结构 → 核心思路与方法选型
  • 实现域：推导算法 + 编码实现 + 验证 → 从思路到可执行方案
  • 优化域：性能优化 + 经验总结 → 提升效率和可复用性
  • 复用/迁移域（可选）：总结归纳 → 提炼通用技巧、模板、口诀

遇到问题先问“问题域”，设计策略先问“设计域”，写代码/验证先问“实现域”，优化性能/经验总结在“优化域”

按“问题→设计→实现→优化”划分

域对应步骤核心目标说明
问题域1️⃣ 分析问题 2️⃣ 寻找问题特征明确需求、约束和规模输入输出、目标、规模，找数据特性、约束条件、目标特性
设计域3️⃣ 选择算法策略 / 技巧 4️⃣ 确定数据结构确定解决问题的算法思想与核心结构算法：包含暴力、分治、贪心、动态规划、回溯、DFS/BFS、滑动窗口、并查集、单调栈、哈希、前缀和等技巧。数据结构：数组、链表、栈、队列、双端队列、堆、树、Trie、图、并查集
**实现域 **5️⃣ 推导算法 6️⃣ 分析复杂度 7️⃣ 验证算法正确性从思路到具体方案，保证正确性和可行性写伪代码、状态转移、边界情况，复杂度分析，小样例验证，理论证明
优化域8️⃣ 优化与实现 9️⃣ 总结归纳提升性能，巩固算法思路剪枝、前缀和、滚动数组、单调栈、哈希优化；总结口诀和经验

常见关键特征

特征类别典型问题域关键特征说明/提示
输入规模n 的大小（10² / 10⁵ / 10⁶），数据量级，是否多组数据规模直接决定算法复杂度范围（O(n²)/O(n log n)/O(n)）
数据范围数值范围（≤10⁹? ≤10¹⁸? ≤10²?），是否负数，小数，精度要求影响存储方式、溢出风险、数据结构选择（数组/哈希/大数）
数据结构特征输入是否天然构成 数组/字符串/树/图/矩阵决定可能的算法策略（DFS/BFS/DP/分治/图算法）
有序性输入是否已排序 / 可排序 / 是否需要保持顺序关联 双指针、二分、排序+扫描 技巧
动态性数据是否 静态（一次性输入）还是 动态更新（插入/删除/修改/查询）决定是否要用 平衡树、堆、并查集、线段树、BIT 等动态数据结构
目标类型求解目标：最值（max/min）、计数、判定、存在性、构造解、路径/方案数不同目标常对应不同算法（判定→二分答案，方案数→DP/组合数学）
约束条件是否有限制条件（必须连续、不能重复、模运算、容量约束）常引导出特定算法：滑动窗口/背包DP/模逆元/约束满足问题
最优性要求是否要求 最优解（最小代价/最短路径）还是 可行解最优解→DP/贪心/最短路；可行解→搜索/构造
解的数量单解 / 多解 / 所有解决定是否需要 枚举/回溯/组合搜索
输出形式数值 / 序列 / 路径 / 结构 / Yes/No指定答案格式，提示可能需要恢复路径或构造解
特殊性质单调性、对称性、周期性、模数性质、稀疏性、低维/高维特性是算法优化的突破口，比如 单调队列、FFT、矩阵快速幂
隐藏条件题目中暗含的边界条件或数学关系常见于竞赛题：比如“图是连通的”“保证有解”“结果不会超过 long long”

思维流程

规模定复杂度，范围看存储； 结构定套路，约束找突破； 目标看最优，输出辨单多。

读题 → 提炼关键元素：输入规模、数据类型、输出目标

检查复杂度边界：规模决定算法上限（n ≤ 100 → 暴力可能；n ≤ 10⁵ → O(n log n)；n ≤ 10⁶ → O(n)）

识别典型特征：

  • 排序性 → 二分/双指针
  • 连续区间 → 前缀和/滑动窗口
  • 树/图结构 → DFS/BFS/最短路/并查集
  • 多组询问 → 预处理/数据结构

归类到题型：对应 数组/字符串/图/数论/组合数学/几何

进入设计域：根据特征选算法策略

常用策略/算法对照表

小规模 → 暴力 / 回溯

中规模 → 排序 / 分治 / 二分 / DP

大规模 → 线性 / 单调结构 / 数学公式

区间问题 → 前缀和 / 差分 / 线段树 / 树状数组

图论问题 → DFS/BFS / 最短路 / MST / 拓扑排序

字符串 → KMP / Trie / 后缀结构

最优解 → 贪心 / DP / 最短路 / 网络流

判定/存在性 → 二分答案 / 并查集 / 搜索

问题域特征常用策略/算法

输出需要构造解/路径回溯/DFS 路径恢复、动态规划路径记录、贪心构造、拓扑序列
