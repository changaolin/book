树莓派基于 Ubuntu系统使用摄像头

测试脚本

1. 检查摄像头连接

确保摄像头正确连接到树莓派，并且连接稳固。尝试重新插拔摄像头。

2. 安装必要的驱动和工具

安装v4l-utils工具以检查和管理视频设备：

sudo apt-get update
sudo apt-get install v4l-utils

使用以下命令检查摄像头是否被识别：

v4l2-ctl --list-devices  # 查看是否有video0节点

3. 确认设备节点

检查是否有视频设备节点：

ls /dev/video*

通常，摄像头设备会被映射到/dev/video0。如果没有看到这些设备节点，可能是驱动问题或摄像头没有正确连接。

4. 检查dmesg日志

使用dmesg命令查看系统日志，检查摄像头连接时是否有错误信息：

dmesg | grep video

5. 使用vsgencmd get_camera测试摄像头

# 注意需要使用sudo
sudo vcgencmd get_camera
# supported=1 detected=1, libcamera interfaces=0 表示支持，

6. 安装和配置OpenCV

确保安装了OpenCV并正确配置。可以使用以下命令安装OpenCV：

sudo apt-get install python3-opencv

然后，尝试运行一个简单的OpenCV程序来捕获摄像头视频 使用sudo ：

import cv2

# 尝试不同的摄像头索引和后端
cap = cv2.VideoCapture(0, cv2.CAP_V4L2)  # 或 cv2.CAP_GSTREAMER

if not cap.isOpened():
    print("Cannot open camera")
    exit()

while True:
    ret, frame = cap.read()
    if not ret:
        print("Can't receive frame (stream end?). Exiting ...")
        break

    cv2.imshow('frame', frame)
    if cv2.waitKey(1) == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

# sudo python3 cv_test.py

7. 使用fswebcam测试USB摄像头

如果你使用的是USB摄像头，可以使用fswebcam工具进行测试：

sudo apt-get install fswebcam
fswebcam test.jpg

这会拍摄一张照片并保存为test.jpg，如果成功，说明摄像头正常工作。

8. 更新系统和固件

确保你的系统和固件是最新的：

sudo apt-get update
sudo apt-get upgrade
sudo rpi-update

9. 关键配置

sudo vim /boot/firmware/config.txt
start_x=1   # 开启摄像头配置
gpu_mem=128  # 摄像头的内存
# 可以尝试注释掉 camera_auto_detect=1 摄像头自动发现

vim /etc/modules
# 新增
bcm2835-v4l2

reboot

10. 普通用户使用摄像头

sudo usermod -aG video $USER # 将用户加入video组
