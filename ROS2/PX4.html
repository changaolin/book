PX4

安装

cd
git clone https://github.com/PX4/PX4-Autopilot.git --recursive
bash ./PX4-Autopilot/Tools/setup/ubuntu.sh
cd PX4-Autopilot/
make px4_sitl

pip install --user -U empy==3.3.4 pyros-genmsg setuptools

安装Agent

git clone https://github.com/eProsima/Micro-XRCE-DDS-Agent.git
cd Micro-XRCE-DDS-Agent
mkdir build
cd build
cmake ..
make
sudo make instcall
sudo ldconfig /usr/local/lib/

# MicroXRCEAgent udp4 -p 8888  请注意，每个连接端口只允许一个代理(Agent)。

在构建 PX4 时，如果遇到 "OpenGL 3.3 is not supported" 的错误，这通常是因为你的系统不支持 OpenGL 3.3 或者相关的驱动程序没有正确安装。这里有几种方法可以尝试解决这个问题：

1. 更新显卡驱动程序

确保你的显卡驱动程序是最新的。对于 NVIDIA 和 AMD 显卡，你可以使用它们各自的官方工具来更新驱动程序。

对于 NVIDIA 显卡：

bash
复制代码
sudo apt update
sudo apt install nvidia-driver-XXX

（将 XXX 替换为你显卡的最新驱动版本）

对于 AMD 显卡：

你可以从 AMD 的官方网站下载并安装最新的驱动程序。

2. 安装必要的软件包

确保你已经安装了所有必要的 OpenGL 库和开发工具。可以尝试安装以下软件包：

sudo apt update
sudo apt install libgl1-mesa-dev
sudo apt install libglu1-mesa-dev

3. 使用虚拟机或远程桌面

如果你在虚拟机或远程桌面环境中运行，可能会遇到 OpenGL 支持的问题。你可以尝试在本地物理机上构建，或者检查虚拟机软件的 3D 加速设置。

4. 安装 Gazebo 和相关依赖项

确保你已经安装了 Gazebo 和所有必要的依赖项。可以参考 PX4 官方文档来安装这些依赖项：

sudo apt install gazebo9 libgazebo9-dev

5. 检查硬件支持

确保你的硬件支持 OpenGL 3.3。你可以使用以下命令来检查你的系统支持的 OpenGL 版本：

glxinfo | grep "OpenGL version"

6. 使用软件渲染

如果你的硬件不支持 OpenGL 3.3，你可以尝试使用 Mesa 3D 的软件渲染：

sudo apt install mesa-utils
export LIBGL_ALWAYS_SOFTWARE=1

# sudo apt install nvidia-utils-535

执行以上命令后，再次尝试构建 PX4。如果问题仍然存在，可以进一步检查 PX4 和 Gazebo 的文档或相关社区论坛，以获取更多帮助。
